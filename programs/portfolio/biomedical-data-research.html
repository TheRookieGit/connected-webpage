Biomedical Data Research: Cancer, Biomarkers, and Epigenetics

Explore a selected computational research question using biological data and transparent analytical methods.

Overview

This program brings together three possible research directions: circulating tumor-cell transcriptomics, extracellular-vesicle and tumor-microenvironment markers, and cell-free DNA methylation. Each learner follows one appropriately scoped track. Dataset access, preparation, and analytical depth are established before the project begins.

Learning goals and possible work

Proposed learning outcomes for this program example:

  • Define a bounded biological question and evaluate dataset suitability.
  • Document an analysis appropriate to one selected data type.
  • Communicate patterns and limitations without diagnostic claims.

Illustrative learning sequence

The sequence below illustrates how this program’s content can be organized. Topics, pacing, and project depth are adapted for each offering. This is not an archived record of a specific cohort’s weekly syllabus.

  1. 01Selecting a biological question and one project track
  2. 02Reading the literature and documenting biological context
  3. 03Data access, licensing, privacy, and study design
  4. 04Preparing data and performing quality checks
  5. 05Exploring patterns with suitable visualizations
  6. 06Selecting an analysis for transcriptomic or methylation data
  7. 07Comparing findings with biological context
  8. 08Checking robustness and potential confounding
  9. 09Writing results and limitations
  10. 10Research poster or analytical report presentation
